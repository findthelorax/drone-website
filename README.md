# DKS Drone Website

Welcome to the DKS Drone website repository! This project showcases a Vermont-based aerial imagery company providing high-quality, affordable drone services to businesses and individuals in Vermont, New Hampshire, New York, and beyond.

## Features

- **Responsive Design**: Optimized for all devices, including mobile, tablet, and desktop.
- **Interactive Animations**: Smooth animations using GSAP and Framer Motion.
- **Dynamic Content**: Fetches and displays dynamic content such as slogans and FAQs.
- **Modern Technologies**: Built with Next.js, React, and Tailwind CSS.
